# Monorepo Migration Report

Generated: 2026-07-01

## Final Architecture

- `frontend/`: ecommerce storefront Vite app.
- `admin/`: admin dashboard Vite app.
- `backend/`: single shared backend, auth system, API, and data store.
- `package.json` and `package-lock.json`: single npm package manager root.
- `dist/frontend` and `dist/admin`: generated build outputs.

## Conflict Handling

- Differing app files with the same old relative path, such as `src/app/components/ui/*`, were kept app-local under `frontend/` and `admin/`.
- Old admin project metadata and nested Git data were preserved under `docs/migration/admin-dashboard-leftovers/` instead of being overwritten.
- `.env` files were moved but their values are intentionally not printed in this report.

## Merged Files

- `package.json`: merged storefront, admin, backend, lint, build, smoke, and database scripts into one root package file.
- `package-lock.json`: regenerated with one root `npm install`.
- `.gitignore`: added root ignores for generated folders, env files, logs, SQLite WAL/SHM files, and runtime backup/token data.
- `backend/.env.example`: updated CORS defaults for both local apps.
- `README.md`, `backend/README.md`, `docs/admin/README.md`, `docs/admin/DEPLOYMENT.md`: updated to the monorepo layout.
- `eslint.config.js`: added root lint config for frontend, admin, backend, and scripts.
